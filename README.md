## 使用

- 启用 HTTPS 解密，并安装、完全信任 MITM 证书；Surge macOS 开启增强模式。
- 喜马拉雅统一使用同一模块，配置处理与广告过滤均在本地完成。更新模块和脚本缓存后冷启动 App 两次；旧 Shadowrocket 地址仍可更新，两个地址只需安装一个。
- 京东比价显示在商品详情页，价格数据来自比价接口。
