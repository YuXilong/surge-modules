## 使用

- 启用 HTTPS 解密，并安装、完全信任 MITM 证书；Surge macOS 开启增强模式。
- 喜马拉雅按客户端选择一个版本，更新模块和脚本缓存后冷启动 App 两次。配置密文由自有服务 `uu.t-wk.com` 处理，广告过滤在本地完成。
- 京东比价显示在商品详情页，价格数据来自比价接口。
